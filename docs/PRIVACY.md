# 隐私说明

1. **克隆本仓库** —— 只有源码和安装脚本，没有账号信息。  
2. **安装** —— 在本地编译，默认生成 `~/Applications/AI Credits.app`（统一双后端菜单栏应用）。  
3. **登录** —— 请用官方 Grok / Codex / ChatGPT 客户端或 CLI 自行登录。  
4. **运行** —— 菜单栏应用读取你主目录下的登录配置，请求官方用量接口；Token/任务统计来自本机日志。  
5. **卸载** —— 删除应用与开机自启项，**不会**删除你的 Grok/Codex 登录态。

本项目的维护者不会收到你的任何凭证或用量数据。
